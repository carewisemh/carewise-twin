# CareWise Twin

## Overview

CareWise Twin is an AI-powered preventive mental wellness application built for the Ontomorph HealthTech Hackathon. It combines daily wellness assessments with Ontomorph's Digital Twin Platform to provide personalized wellness insights and recommendations.

## Features

- Daily wellness check-in
- Wellness Summary
- Wellness Score
- AI-powered recommendations
- Personalized Care Plan
- Ontomorph Digital Twin integration
- Responsive healthcare dashboard

## Tech Stack

- Next.js 16
- TypeScript
- Ontomorph DTP SDK
- Lucide React

## Installation

Clone the repository:

```bash
git clone https://github.com/carewisemh/twin.git
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
DTP_API_KEY=your_api_key
DTP_GRANT_TOKEN=your_grant_token
```

Run the application:

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```
